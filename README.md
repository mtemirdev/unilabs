### Учебный проект: Лабораторные работы по Java

Данный репозиторий содержит комплект лабораторных работ по программированию на языке Java, охватывающий путь от баз объектно-ориентированного программирования до создания графических приложений с пользовательским интерфейсом (GUI на Swing), обработки событий и 2D-графики.

#### 📁 Структура проекта и пакетов

Проект организован по логическим модулям (пакетам) в соответствии с правилами чистого кода (Clean Code) и общепринятыми соглашениями наименования пакетов Java (package naming conventions):  
src/  
├── oop/                 \# Лабораторные работы №1–3: Основы ООП, массивы, коллекции, Javadoc  
├── gui/               \# Лабораторные работы №4–6: Графический интерфейс, события, меню и Graphics2D  
├── io/                  \# Лабораторная работа №7: Файловый ввод-вывод, JList, HashMap, сборка JAR  
└── db/                  \# Лабораторная работа №8: Работа с базами данных (JDBC, H2 / SQLite, SQL)

#### 🚀 Описание лабораторных работ

##### 📦 Модуль oop (Лабораторные работы №1–3)

* **Тематика** : Базовый синтаксис Java, ООП, работа с памятью и структурирование кода.  
* **Ключевые темы** :  
* Классы, объекты, конструкторы, поля и методы.  
* Инкапсуляция, наследование и полиморфизм (extends, super, override).  
* Массивы и динамические коллекции (ArrayList).  
* Документирование кода с помощью  **Javadoc**  (@param, @return, @author).

##### 🖼️ Модуль gui (Лабораторные работы №4–6)

###### *Лабораторная работа №4: Создание GUI на Java Swing*

* **Цель** : Оосвоение базовых компонентов библиотеки Swing и менеджеров компоновки.  
* **Ключевые классы и технологии** :  
* **Контейнеры** : JFrame, JPanel, Box.  
* **Менеджеры компоновки** : BorderLayout, FlowLayout, GridLayout, BoxLayout.  
* **Визуальные элементы** : JButton, JLabel, JTextField, JTextArea, JCheckBox, JRadioButton, ButtonGroup.  
* **Паттерны** : Использование массивов/списков объектов (JButton) при наличии более 3 однотипных компонентов.  
* **Реализованные классы** :  
* MyFrame.java / MyFrame\_v2.java — демонтрация базовой компоновки окна со всеми видами Layout Managers.  
* CalculatorWindow.java (Вариант 5\) — графическая форма калькулятора с текстовым полем ввода (JTextField) и сеткой кнопок 1..3.

###### *Лабораторная работа №5: Модель обработки событий (Event Handling)*

* **Цель** : Изучение реактивного интерфейса, слушателей и адаптеров событий.  
* **Ключевые классы и технологии** :  
* **Слушатели** : ActionListener, ChangeListener, MouseWheelListener.  
* **Классы-адаптеры** : MouseAdapter, KeyAdapter.  
* **Реализованные классы** :  
* CalculatorWindowEvents.java (Вариант 5\) — интерактивное приложение, поддерживающее:  
* ActionListener: добавление цифр с кнопок в текстовую строку.  
* MouseAdapter: динамическая подсветка кнопок жёлтым цветом при наведении курсора.  
* MouseWheelListener: масштабирование размера шрифта текстового поля с помощью колесика мыши (от 10pt до 36pt).  
* KeyAdapter: быстрая очистка поля ввода по нажатию клавиши  **Escape** .

###### *Лабораторная работа №6: Меню и 2D-графика (Graphics2D)*

* **Цель** : Создание иерархических меню и вычерчивание произвольной векторной графики.  
* **Ключевые классы и технологии** :  
* **Меню** : JMenuBar, JMenu, JMenuItem.  
* **Графика** : Graphics2D, переопределение paintComponent(Graphics gr).  
* **Стили и фигуры** : BasicStroke (сплошные и пунктирные линии, разная толщина), GradientPaint (градиентная заливка), drawLine(), drawOval(), drawArc(), drawRoundRect().  
* **Реализованные классы** :  
* MenuGraphicsWindow.java — окно с выпадающим меню «Фигуры», управляющим перерисовкой геометрических объектов на кастомной панели.  
* SurnameGraphicsWindow.java (Вариант 5\) — художественная отрисовка букв фамилии векторными линиями разной толщины, пунктира, цвета и градиента с декоративной рамкой.

##### 💾 Модули io и db (Перспектива: Лабораторные работы №7–8)

* **package io** : Работа с файловыми потоками (BufferedReader, BufferedWriter), визуальные списки JList, хэш-таблицы HashMap, экспорт проекта в исполняемый .jar файл.  
* **package db** : Подключение к реляционным базам данных через JDBC, выполнение SQL-запросов (SELECT, INSERT, UPDATE), вывод данных в формы JTable.

#### 🛠️ Требования к окружению и запуск

1. **Java Development Kit (JDK)** : версия 17 или выше.  
2. **Среда разработки (IDE)** : IntelliJ IDEA, Eclipse или NetBeans.  
3. **Кодировка исходников** : UTF-8.

##### Инструкция по запуску:

* Клонируйте репозиторий или откройте папку проекта в вашей IDE.  
* Убедитесь, что исходный код находится в директории src/.  
* Для запуска любого из классов откройте нужный файл (например, src/swing/CalculatorWindowEvents.java) и выполните запуск метода main:  
* В  **IntelliJ IDEA** : Нажмите Shift \+ F10 или зелёный треугольник напротив public static void main.  
* В  **Eclipse** : Нажмите Ctrl \+ F11 или выберите Run As \-\> Java Application.

#### 📝 Стандарты оформления кода

* **Именования** : Классы называются с заглавной буквы (CamelCase), пакеты — строчными буквами (lowercase), переменные и методы — с строчной буквы (lowerCamelCase).  
* **Модульность** : Создание GUI-компонентов разделяется по логическим методам или классам, избегая громоздкого кода в main.  
* **Безопасность потоков Swing** : Запуск графических окон рекомендуется выполнять через SwingUtilities.invokeLater().
